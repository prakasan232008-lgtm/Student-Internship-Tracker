# Student Skill & Internship Tracker

A Java Swing desktop application for managing student skills and internship records.

## Features

- Add Student
- Add Skill
- Add Internship
- View Students
- View Skills
- View Internships
- Search Student
- Update Internship
- Progress Report
- Student Profile
- Linked Records
- Delete Records
- Save Data
- Dashboard Statistics

## Technologies

- Java
- Java Swing
- ArrayList
- File Handling
- Object-Oriented Programming

## Run

Compile:

javac *.java

Run:

java TrackerGUI
